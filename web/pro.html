CostDiff Pro : en préparation

La version gratuite reste gratuite. La version Pro n'existe pas encore : avant de la construire, nous voulons savoir ce qui vous ferait vraiment gagner du temps.

Ce qui est envisagé

  • Mémoriser les colonnes de chaque fournisseur (plus rien à régler le mois suivant).
  • Garder l'historique des tarifs pour voir l'évolution d'un article sur un an.
  • Être alerté quand un nouveau tarif dépasse vos seuils.
  • Export Excel mis en forme.

Rien n'est promis : ces fonctions seront construites seulement si elles sont demandées. Prix indicatif à l'étude : 12 € par mois.

Votre avis

Quelques questions : utiliseriez-vous CostDiff, à quelle fréquence comparez-vous des tarifs, que manque-t-il ? Pas de compte à créer. Votre adresse e-mail est facultative ; elle ne sert qu'à vous recontacter au sujet de CostDiff Pro si vous l'acceptez.

N'envoyez jamais de tarif fournisseur ni de prix confidentiels dans vos messages, vos issues ou le questionnaire.

Répondre au questionnaire

Dites-nous ce qu'il vous faudrait : par une issue GitHub (publique, compte GitHub nécessaire).

Le questionnaire est hébergé par Tally (Belgique, Union européenne). Détails dans la page Confidentialité.

Nous écrire

Sans compte : chaque lien ouvre votre messagerie avec un objet déjà rempli.

  • Une question sur CostDiff
  • Signaler un problème (dites-nous le format du fichier et ce qui s'affiche, sans joindre le fichier)
  • Proposer une amélioration
  • Être prévenu de la version Pro
  • Demander une démonstration (15 minutes en visio, avec les fichiers d'exemple)

Pour l'instant : une issue GitHub (publique, compte GitHub nécessaire).

Ne joignez jamais de tarif fournisseur ni de prix confidentiels. Vos messages servent uniquement à vous répondre (voir Confidentialité).
